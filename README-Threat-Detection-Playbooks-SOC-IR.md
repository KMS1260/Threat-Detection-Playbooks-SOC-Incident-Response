# 🛡️ Threat Detection, Playbooks & SOC IR

This repository documents hands-on work in **threat detection**, **SOC playbooks**, and **incident response**, applying practical techniques to detect, triage, and remediate security events across endpoints and networks.
Projects are treated as standalone case studies.

Each project includes:
- Objectives
- Tools & techniques used
- Step-by-step walkthroughs
- Sample outputs
- Key takeaways
